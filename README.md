# ThinkFix 🧠📊

ThinkFix is a **full-stack EdTech web application** designed to help students (JEE/NEET) identify conceptual mistakes in their answers and help coaches analyze class-level learning gaps.

This project is built as part of a learning / internship-ready full-stack system using **Next.js, Node.js, Express, and MongoDB**.

---

## 🚀 Features

### 👤 Student Module
- Role-based authentication (Student / Coach)
- Register & Login with JWT authentication
- Submit answers (text-based)
- Get diagnostic feedback:
  - Error type (conceptual / calculation / procedural)
  - Root cause of mistake
  - Correct approach & next steps
- View past attempts (history)
- Student dashboard with stats

### 📊 Coach Module
- Role-based login
- Class-level analytics
- Identify high-risk topics
- View student performance trends

---

## 🛠 Tech Stack

### Frontend
- **Next.js (App Router)**
- TypeScript
- Tailwind CSS
- Lucide Icons

### Backend
- **Node.js**
- **Express.js**
- MongoDB (Mongoose)
- JWT Authentication
- bcrypt (password hashing)
